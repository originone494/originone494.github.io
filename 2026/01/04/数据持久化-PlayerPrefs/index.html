数据持久化-PlayerPrefs

发表于 2026-01-04 分类于 Unity
本文字数： 1.2k 阅读时长 ≈ 2 分钟

一、什么是数据持久化#

数据持久化是将内存中的数据模型转换为存储模型，以及将存储模型转换为内存中的数据模型的统称。
说人话：将游戏数据存储到硬盘，硬盘中数据读取到游戏中，也就是传统意义上的存盘。

二、PlayerPrefs是什么#

PlayerPrefs是Unity提供的可以用于存储玩家数据的公共类。

三、PlayerPrefs存储相关#

PlayerPrefs的数据存储，类似于键值对存储，一个键对应一个值。
键：string
值：int float string

四、PlayerPrefs读取相关#

运行时，只要使用了set，及时没有save，也可以读取信息。

五、PlayerPrefs删除相关#

六、PlayerPrefs存储的数据在哪里#

Windows：计算机\HKEY_CURRENT_USER\SOFTWARE\Unity\UnityEditor[公司名][产品名]
Android：/data/data/包名/shared_prefs/pkg-name.xml
IOS：/Library/Preferences/[应用ID].plist

七、PlayerPrefs数据唯一性#

PlayerPrefs数据唯一性是由key决定的，不同的key决定了不同的数据。
同一项目中，如果不同数据key相同，就会造成数据丢失。
要保证数据不丢失就必须保证key唯一的原则。
