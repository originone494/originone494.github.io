二、OpenAI库的基本使用#

  1. ChatCompletion 对象

client.chat.completions.create 可以创建 ChatCompletion 对象，主要参数有两个：

model：选择所用模型

message：提供给模型的消息，类型为 list ，里面可以包含多个字典消息，每个字典包含两个 key ， role ：角色，和 content ：内容。

若 role 为 system ，则可以设定助手的整体行为、角色和规则，为对话提供上下文框架（如指定助手的身份、回答风格、核心要求），是全局的背景设定，影响后续所有交互。

若 role 为 assistant ，代表 AI 助手的回答，可以在代码中人为设定。

若 role 为 user ，代表用户发送的问题、指令和需求。

每个 ChatCompletion 对象都包含以下信息，我们可以通过 print(response.choices[0].message.content) 输出模型给出的回答信息。

  1. 流式输出

在使用 client.chat.completions.create 调用 ChatCompletion 对象时，增加参数：stream = True 。

  1. 附带历史消息

message 中的可以包含很多消息，我们可以将历史消息填入，让模型知晓对话的上下文。

四、RAG介绍#

RAG 是检索增强生成技术，利用检索外部文档提升生成结果质量。

简单来说， RAG 工作分为两个流程。

为什么要使用 RAG ？

因为通用的基础大模型存在一些问题：

· 知识不是实时的，模型训练好后不具备自动更新知识的能力，会导致部分信息滞后。

· 缺乏领域知识，大模型的知识来自训练数据，主要来自公开的互联网和开源数据集，无法覆盖特定领域或高度专业化的内部知识。

· 幻觉问题，大模型可能会生成看似合理，实际上是错误的回答。

· 保证数据安全性。

五、向量的概念#

RAG 流程中，向量库是一个重要的节点。

向量（Vector）是文本的“数字身份证”，它将一段文本的语义信息，转换成一段固定长度的数字列表，让计算机能够“看懂”文字的含义并做相似度计算。

简单来说，就是让计算机更方便地理解不同的文本意思，是否在表述同一个意思。

在向量嵌入的过程，我们可以使用文本嵌入模型，通过深度学习等技术，从文本提取语义特征并映射为固定长度的数字序列。

在向量匹配的过程，如何识别2段文本是否表述相似的意思，主要通过余弦相似度等算法来完成。

如何进行更为精准的语义匹配，生成向量的维度是一个很重要的指标。

如某个模型可以生成 1536 维的向量，一段文本固定得到 1536 个数字序列。 1536个数字表示这段文本在 1536 个主题（抽象的语义特征）方向上的得分（强度）。

六、余弦相似度#

在文本向量语义匹配中，余弦相似度是衡量两个向量方向相似程度的核心算法，即判断两段文本语义是否相近。

向量的数字序列，共同决定了向量在高维空间中的方向和长度。

而余弦相似度主要是撇除长度的影响，得到方向的夹角，夹角越小越相似，即方向相同。

以一维向量为例，一个 0.5 和 -0.5 的向量方向相反，夹角较大，一个 0.5 和 1 的向量，方向相同，夹角更小。

以二维向量为例，一个 [0.5,0.5] 和 [0.5,-0.5]的向量显然存在夹角，夹角更小的两个向量更加相似。

余弦相似度 = 两个向量的点积 / 两个向量模长的乘积

七、LangChain 安装#

LangChain 的核心理念是为各种 LLMs 实现通用接口，并不去开发 LLMs 。

在命令行中执行指令： pip install langchain langchain-community dashscope chromadb

其中 langchain 是LangChain的核心包。

langchain-community 是社区支持包。

dashscope 是阿里云通义千问的 Python SDK 。

chormadb 是轻量向量数据库。
