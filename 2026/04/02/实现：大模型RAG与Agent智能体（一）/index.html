首先创建 app_file_loader.py 文件

这个文件的功能是基于 Streamlit 完成 WEB 网页上传服务

首先安装 streamlit

在命令行执行指令 pip install streamlit

安装后写一个简单的代码测试

在 pycharm 的终端（也可以 cd 进项目的根目录）执行指令 streamlit run app_file_uploader.py

之后可以看到弹出来的网址，点开网址，看到效果。

如果出现了报错：‘streamlit’ 不是内部或外部命令，也不是可运行的程序

那么应该是环境配置出了问题。

我的做法是使用 everything 搜索 streamlit

找到 streamlit.exe 文件

将其所在的目录添加至环境变量中

之后重启 pycharm ，问题解决。
