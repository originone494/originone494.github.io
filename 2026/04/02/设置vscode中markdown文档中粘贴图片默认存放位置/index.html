设置vscode中markdown文档中粘贴图片默认存放位置

发表于 2026-04-02 分类于 常见问题
本文字数： 287 阅读时长 ≈ 1 分钟

正文#

在使用markdown写文本的时候，难免需要在文中插入图片。

我的博客所使用的结构会将一篇文章里所需要的图片放在同名文件夹下，就像这样。

但在 vscode 中，使用截图键，然后将图片直接粘贴到文本编辑器中，图片会默认放在 .md 文件的同一个目录下。

因此，我每次粘贴完图片，都需要将图片手动移动到同名的文件夹下。

不过在 vscode 中可以进行设置，解决这个问题。

打开设置，搜索 markdown 点开 C/C++ 选项下的 markdown(40) ，进行设置，和图中一样

然后就可以愉快地使用粘贴图片的功能了。
